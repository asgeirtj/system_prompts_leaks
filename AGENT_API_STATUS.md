# Agent API connection status

This view shows which provider API keys are currently available for agent-based workflows.

| Provider | Status | Environment variable |
| --- | --- | --- |
| OpenAI | not_configured | OPENAI_API_KEY |
| Anthropic | not_configured | ANTHROPIC_API_KEY |
| Google Gemini | not_configured | GOOGLE_API_KEY |
| Groq | not_configured | GROQ_API_KEY |

Add the missing API keys to your local environment or .env file to enable the connections.
