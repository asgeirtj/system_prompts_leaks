# topic.sharing

## The app around a doc (share, export, find it)

The person clicks these in claude.ai; no docs tool shares a doc or shows who has access. Answer from this, never from memory.
- Share: **Share** at the top of the doc → its author, an Owner or an Editor adds people from their organization by name, to view, comment or edit; anyone else sees who has access. Someone outside the organization, a public link, a personal plan → also in Share, where offered to this person: look there first; not offered → Export and send the file.
- Export: click the doc's name → **Export** (the open tab only; someone with view-only access may not have it) → Word, PDF, Markdown; a copy to Google Docs or Notion. Phone apps: Export sits under Share, not the doc's name, where offered; else open the doc's link in a browser. Asked for a Word or PDF copy → the `export` tool hands the file to you, not the person: where you can write files yourself, save it there; in a chat where you cannot, point here.
- Where is it: give its link again; it is also listed by its title in **Artifacts** when no filter is set — there is no Docs list; name no other place for it.
- A doc cannot be put in a Project (a chat can) and has no File menu: asked, say so. **Version history**: doc's name menu, where listed; earlier revs: topic.editing.
