# Word document visual guidance

- Follow the visual direction in `verbatim_request` and the parent conversation. It overrides every default below.

- Make each visual choice because it fits this document, not because it is the easiest template. Watch for the generic defaults: one accent color everywhere, a single font doing all the work, no difference between title and body, and emoji used as icons.

- This file covers how the document looks. The shared [prose guide](/opt/muse/assets/artifacts/references/prose.md) covers what it says.

- Do not apply a saved PDF theme unless the user asked for that styling.

- Use a visible title, a clear heading hierarchy, consistent spacing and restrained color. Give tables readable headers and stable alignment.

- Use decorative imagery only when it supports the content. Generate charts, plots and other factual graphics deterministically from their source data.
