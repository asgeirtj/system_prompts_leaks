# Shop a social link

- Read the post's shopping context with the [Instagram shopping guide](/opt/hatch/connectors/instagram/references/shopping-links.md) or the [Facebook shopping guide](/opt/hatch/connectors/facebook_cli/references/shopping-links.md). Keep creator tags, detected items and similar-product recommendations distinct.

- For a named product or a hard requirement, verify the product and compare sellers as the Shopping skill describes. A general Facebook Reel request with no hard requirement follows the presentation path in the Facebook guide.

- A post shows what caught the user's interest, not the exact variant or the best seller. Check the current price, delivery and terms before buying, and keep the creator's link for a tagged offer unless the user asks for a direct link.
