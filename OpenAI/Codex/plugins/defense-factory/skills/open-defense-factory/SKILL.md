# Codex Security Cloud

Use the connected Codex Security Cloud app's `open_defense_factory` tool to open its interactive UI. If the tool is not loaded, discover it through the available tool search.

The UI uses the current ChatGPT workspace and its existing Cloud and security permissions. Let its setup controls handle GitHub connections and Cloud environments. Do not request credentials or change workspace permissions to make a request succeed.

Use the UI for repository selection, scan setup, and finding triage. Opening the app does not authorize starting scans, changing findings, or creating pull requests.
