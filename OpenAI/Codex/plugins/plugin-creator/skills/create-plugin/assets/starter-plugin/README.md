# Starter plugin

Customize this folder before publishing it:

1. Rename the folder and update the name, description, author, and interface in
   `plugin.json` for the requested workflow.
2. Rename `skills/starter-workflow/`, update its `name` and `description` in  
   `SKILL.md`, and replace the placeholder instructions with a real workflow.
3. Add only the apps or MCP servers the plugin needs. If you add an icon, put
   the image in this folder and reference its relative path in `plugin.json`.

The starter has no connected apps, MCP servers, or icon.
