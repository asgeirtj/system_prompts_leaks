# Presentations

Presentations is the file-type wrapper plugin for presentation slide deck workflows.

This plugin is bundled into the Codex primary runtime.

## Included Skills

- `Presentations`: create, edit, render, verify, and export editable PowerPoint and Google Slides presentation decks.

## Skill Resources

- `routing/`: native Google Slides routing and cross-plugin handoff.
- `references/template-following.md`: exact source-deck/template-following workflow.
- `template_following_scripts/`: source inspection, frame-map validation, starter-deck, and fidelity helpers.
- `builtin_templates_support/`: checked-in guidance, manifests, prompts, and shared runners for bundled templates.
- `assets/builtin_templates/`: runtime-mounted static template assets, including the 26-layout Codex Grid library.
- `style_guidelines.md`: required narrative, copy, layout, and typography guidance.
- `artifact_tool_docs/` and `container_tools/`: authoring, rendering, and validation support.

## Discoverability

Use this plugin for presentation-oriented terms from the file-type naming model: slides, deck, PowerPoint, Google Slides, presentation, presentations, PPT, and `.pptx`.

## Source And Copy Flow

This plugin package is generated from `lib/artifacts/artifacts_skills` and copied into `plugins/presentations` through `lib/artifacts/artifacts_skills/mapping.json`.
