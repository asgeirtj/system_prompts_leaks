# Domain and deployment strategy

## Goal
Create a professional public URL for the platform without needing to pay much upfront.

## Recommended free or low-cost route
1. Use a free hosting platform such as Vercel, Netlify, or Cloudflare Pages for the frontend.
2. Use a free or low-cost backend host such as Render or Railway.
3. Use a free subdomain from the platform provider initially.
4. Later, connect a custom domain if you want a more professional appearance.

## Best practical options
- Vercel / Netlify subdomain: easiest and free
- Cloudflare Pages: good for static pages and frontends
- Render / Railway: simple backend deployment
- Cloudflare DNS: useful for pointing a custom domain later

## Suggested approach
- Start with a branded subdomain like `yourproject.vercel.app`.
- Once traction grows, buy a low-cost domain from a registrar or use a free custom domain option if available.
- Keep the backend and frontend separated so the domain remains flexible.

## Business note
A domain improves trust and conversion, but it is not mandatory to start. The product should first prove value through usage and lead capture.
